# JARVIS Sound Packs

Place audio files in each folder with the following names:

## Required Files Per Voice Pack

Each voice pack folder needs these 6 files:
- `startup.mp3` - Plays when JARVIS boots up
- `boot-complete.mp3` - Plays when boot sequence finishes
- `notification.mp3` - General notification sound
- `error.mp3` - Error/alert sound
- `success.mp3` - Task completed sound
- `thinking.mp3` - Processing/thinking loop

## Root Level Sound

Place in `/sounds/` root:
- `shoot-to-thrill.mp3` - AC/DC Shoot to Thrill for startup sequence

## Voice Pack Folders

```
/sounds/
├── shoot-to-thrill.mp3     <- Main startup music
├── JARVIS/                  <- JARVIS Classic (cyan theme)
├── friday/                  <- F.R.I.D.A.Y. (blue theme)
├── edith/                   <- E.D.I.T.H. (purple theme)
├── JARVIS/                  <- JARVIS (red theme)
├── vision/                  <- VISION (yellow theme)
├── karen/                   <- KAREN (pink theme)
├── baymax/                  <- BAYMAX (white theme)
└── suit-lady/               <- Suit Lady (gray theme)
```

## Recommended Sound Sources

### Iron Man HUD Sounds
- Search YouTube for "Iron Man JARVIS sound effects"
- Download from: https://freesound.org (search "sci-fi UI")
- Create with: https://sfxr.me/ (retro synth sounds)

### Character-Specific Sounds
- JARVIS: Soft beeps, elegant British AI tones
- FRIDAY: Snappier, more casual sounds
- JARVIS: Darker, more menacing tones
- VISION: Warm, harmonic tones
- KAREN: Friendly, approachable beeps
- BAYMAX: Soft, medical/caring sounds

### Music
- Shoot to Thrill by AC/DC - Purchase or use from your music library
- Alternative: Use royalty-free epic rock from https://incompetech.com

## Audio Format

- Format: MP3 (preferred) or WAV
- Bitrate: 128-320 kbps
- Duration:
  - startup.mp3: 2-5 seconds
  - boot-complete.mp3: 1-2 seconds
  - notification.mp3: 0.5-1 second
  - error.mp3: 0.5-1 second
  - success.mp3: 0.5-1 second
  - thinking.mp3: 2-5 seconds (can loop)
  - shoot-to-thrill.mp3: Full song or 30-60 second clip
