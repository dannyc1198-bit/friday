## Directory Purposes

**apps/web/src/app/**
- Purpose: Next.js App Router pages and API routes
- Contains: page.tsx, layout.tsx, api routes
- Key files:
  - `page.tsx` - Main application page
  - `layout.tsx` - Root layout with metadata
  - `api/chat/route.ts` - Stub chat endpoint
  - `api/health/route.ts` - Health check

**apps/web/src/components/**
- Purpose: React UI components
- Contains: All frontend components
- Key files:
  - `ChatPanel.tsx` - Main chat interface
  - `InputBar.tsx` - Message input
  - `Sidebar.tsx` - Conversation list
  - `StartupSequence.tsx` - Iron Man boot animation
  - `ToolControlPanel.tsx` - Control Center (Ctrl+K)
  - `VoiceConfig.tsx` - Voice settings panel

**apps/orchestrator/src/services/**
- Purpose: Business logic services
- Contains: OpenAI, conversation, intent services
- Key files:
  - `openai.ts` - GPT-4 streaming integration
  - `conversation.ts` - Conversation state management
  - `intent.ts` - Intent classification

**apps/orchestrator/src/tools/**
- Purpose: Tool implementations for AI function calling
- Contains: Tool definitions and registry
- Key files:
  - `registry.ts` - Tool registration and execution
  - `index.ts` - Tool initialization
  - `pc-control.ts` - Windows automation via PowerShell
  - `smart-home.ts` - Alexa/Home Assistant integration
  - `media.ts` - Spotify integration
  - `bluetooth.ts` - Windows Bluetooth control

**apps/orchestrator/src/config/**
- Purpose: Configuration and environment management
- Key files:
  - `index.ts` - Config loading and defaults

**apps/orchestrator/src/types/**
- Purpose: Shared TypeScript types
- Key files:
  - `index.ts` - Tool, Message, Conversation types

**Documentation:**

- `CLAUDE.md` - AI assistant guidelines

## Naming Conventions

**Files:**
- kebab-case for most files (route.ts, index.ts)
- PascalCase for React components (ChatPanel.tsx)
- lowercase for config files (tsconfig.json)

**Directories:**
- lowercase for all directories
- Plural for collections (components/, services/, tools/)

**Special Patterns:**
- `index.ts` for barrel exports
- `route.ts` for Next.js API routes
- `page.tsx` for Next.js pages
- `*.test.ts` for tests (not yet present)

## Where to Add New Code

**New Tool:**
- Implementation: `apps/orchestrator/src/tools/{tool-name}.ts`
- Registration: Add to `apps/orchestrator/src/tools/index.ts`
- Types: Add to `apps/orchestrator/src/types/index.ts` if needed

**New API Endpoint:**
- Orchestrator: Add to `apps/orchestrator/src/index.ts` or create route file
- Frontend stub: `apps/web/src/app/api/{endpoint}/route.ts`

**New Component:**
- Implementation: `apps/web/src/components/{ComponentName}.tsx`
- Types: `apps/web/src/types/` if shared

**New Service:**
- Implementation: `apps/orchestrator/src/services/{service-name}.ts`
- Export: Add to `apps/orchestrator/src/services/index.ts`

**New Hook:**
- Implementation: `apps/web/src/hooks/use{HookName}.ts`

## Special Directories

**apps/web/.next/**
- Purpose: Next.js build output
- Source: Auto-generated by Next.js build
- Committed: No (.gitignore)

**apps/web/node_modules/**
- Purpose: npm dependencies
- Source: npm install
- Committed: No (.gitignore)
