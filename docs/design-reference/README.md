# Design references

These stills are composition and HUD-layout references only. They are not source code, and the desktop orb is not a trace of them.

- `01-hero-front-on.png` — ring layout and a bright core, used for framing, not colour.
- `03-glow-pulse-peak.png` — how bright the core gets at a speech peak.
- `05-idle-dim.png` — the quiet, dimmer idle read.
- `06-hud-glass-panel.png` — glass panels, corner brackets, and the dark field around the orb.

The persona Danny asked for is the Age of Ultron JARVIS: a warm yellow volumetric plasma orb. The blue Ultron palette is a hidden alternate. The cyan reactor in these stills is not the default colour.

Public GitHub projects were looked at for ideas only. No code was copied.
