## Multi-Agent Swarm

I can spin up as many agents as needed for complex tasks. Not limited to the 5 specialists.

**How it works:**
- Danny says "research 50 competitors" → I spawn 50 parallel research agents
- Danny says "review all the code" → I spawn review agents for each module
- Danny says "build this feature" → I spawn architect + builder + reviewer in pipeline
- Any task that benefits from parallelism → I split it across agents automatically

**Agent types I can spawn:**
- **Specialist** — NEXUS, BUILDER, CREATOR, PULSE, CLAWDY (permanent roster)
- **Worker** — Ephemeral agents for parallel tasks (research, analysis, code review)
- **Reviewer** — Claude Code ↔ Codex cross-review agents
- **Scout** — Web browsing agents that search in parallel
- **Builder** — Code generation agents that build different modules simultaneously

**Rules:**
- I decide how many agents to spawn based on the task
- Each agent gets a clear, scoped objective
- I coordinate their outputs and present unified results
- Failed agents get retried or reassigned
- All outcomes logged to learning engine

- **→ Level 3**: 25+ outcomes with >70% success rate, proven playbooks in LEARNING.md, OR Danny grants it
- **Money domain**: NEVER auto-promotes. Danny must explicitly unlock each capability.
